# LlamassageApp

A work-in-progress project combining **Flutter** and **Godot**. Development is currently focused on bringing the two parts together in the `flutter-godot` branch.


> **Status: Under active development.** The project is incomplete, and its structure, features, and setup may change as development continues.

## Current development status

The repository contains two development branches:

| Branch | Contents | Status |
| --- | --- | --- |
| [`main`](https://github.com/kuboch17/flutter-godot-llamasageapp/tree/main) | Godot portion of the project | Partially implemented; not a finished standalone release |
| [`flutter-godot`](https://github.com/kuboch17/flutter-godot-llamasageapp/tree/flutter-godot) | Combined Flutter + Godot implementation | Active development branch; integration is in progress |

**Start with `flutter-godot` to follow the current development work.** The `main` branch does not yet contain the combined Flutter + Godot application.

## Technology

- **Flutter**
- **Godot Engine**

The current focus is developing the combined application and its Flutter–Godot integration. A complete feature overview and verified setup instructions will be added as the implementation takes shape.

## Get the source

### Flutter + Godot — active development

```bash
git clone --branch flutter-godot https://github.com/kuboch17/flutter-godot-llamasageapp.git
cd flutter-godot-llamasageapp
```

### Godot — main branch

```bash
git clone --branch main https://github.com/kuboch17/flutter-godot-llamasageapp.git
cd flutter-godot-llamasageapp
```

If you already have a local clone, commit or stash any local changes before switching branches:

```bash
git fetch origin
git switch flutter-godot
```

Cloning the repository only downloads the source. Running the combined application requires additional setup; step-by-step instructions, required Flutter and Godot versions, and supported platforms are not yet documented here.
